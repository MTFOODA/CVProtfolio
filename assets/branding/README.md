# Brand assets

The current gray/sky identity is generated by `python tools/create_identity.py`.
Its editable source is `brand_mark.svg`; see
[`docs/VISUAL_IDENTITY.md`](../../docs/VISUAL_IDENTITY.md) for palette and motion.
Then run `dart run flutter_launcher_icons` for all platform outputs. The
JPEG-derived artwork described below is the previous identity, retained for
reference; running the older script replaces the current masters.

Current assets use the approved continuous CV ligature (proposal 4) in
`brand_mark.svg`, with sky blue `#6CABDD` on graphite `#2D333B`. The supplied
banner `CV & Portfolio Builder logo.jpg` remains unchanged at the repository root.

| File | Size | Purpose |
| --- | --- | --- |
| `app_icon.png` | 1024x1024 | Square emblem plate for the legacy Android mipmaps, the Windows `.ico` and app stores |
| `app_icon_foreground.png` | 1024x1024 | Android adaptive foreground: full-bleed 108 dp layer with the emblem inside the 66% safe zone |
| `app_icon_web.png` | 1024x1024 | Web favicon and PWA icons: content inside the 80% maskable safe circle |
| `app_logo.png` | 512x512 | In-app logo (`kAppLogoAsset`, sign-in screen) |
| `portfolio_link_logo.png` | 256x256 | White tile with a transparent CV cutout, tinted like the other portfolio contact icons |

The current emblem is rendered directly from vector geometry. Small icon sizes
omit the product wordmark to keep the CV monogram legible. The in-app PNG uses
transparent rounded corners; platform masters are full bleed for native masks.
The SVG and PNG masters share the same vector commands in `create_identity.py`.
The previous identity is backed up locally in `build/identity-before-monogram.zip`.

The display name is defined once in `lib/core/branding/app_branding.dart`
(`kAppDisplayName`) and mirrored in the platform metadata listed below.

## Regenerate

```sh
python tools/create_identity.py         # current vector and raster masters
dart run flutter_launcher_icons         # Android mipmaps, web, Windows (config in pubspec.yaml)
```

Android adaptive icons come from `app_icon_foreground.png` with
`adaptive_icon_foreground_inset: 0`: the plugin's 16% default inset would shrink
the already-padded layer and expose the background plate around it.

iOS icons are disabled (`ios: false`) because this project has no `ios/`
platform folder; add the platform with `flutter create --platforms=ios .` and
switch the flag to `true` to generate them.

## Where the name lives

| Surface | File |
| --- | --- |
| Android launcher label | `android/app/src/main/AndroidManifest.xml` (`android:label`) |
| Web tab title, description, Apple web-app title | `web/index.html` |
| PWA `name`, `short_name`, `description` | `web/manifest.json` |
| Windows window title | `windows/runner/main.cpp` |
| Windows file/product metadata | `windows/runner/Runner.rc` |
| Package description | `pubspec.yaml` |
| In-app name (sign-in screen, MaterialApp title) and PDF metadata | `lib/core/branding/app_branding.dart` |
